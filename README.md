# Professional Cover letter generator

This project creates a chatbot API that simulates a phi model from gaianet agent. The AI focuses on job related cover letters and since the cover letters are a crucial part of getting a job this AI has some real world implications.

## Prerequisites

- [Node.js](https://nodejs.org/) (v14 or above)
- npm or yarn (package managers)
- To start - Node index.js

## Smart PR Assistant

This tool helps analyze GitHub pull requests by providing a summary of changes, including:

- Total files changed, additions, and deletions
- Files grouped by type/extension
- Flags for test files and documentation updates
- Detailed list of all changed files

### Requirements

- [GitHub CLI](https://cli.github.com/) installed and authenticated
- Node.js

### Usage

```bash
# Make the script executable (Unix/Linux/macOS)
chmod +x ./public/smart-pr-assistant.js

# Run the script
node ./public/smart-pr-assistant.js
```

The script will fetch the latest open pull request in the current repository and provide a detailed analysis.
